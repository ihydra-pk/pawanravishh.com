# pawanravishh.com

My personal portfolio and blog built with Astro.

🌐 **Live Site:** [pawanravishh.com](https://pawanravishh.com)

## About

This repository contains the source code for my portfolio website, showcasing my projects, skills, and blog posts.

## Tech Stack

- **Astro** (81.8%) - Static site generator
- **CSS** (7.4%) - Styling
- **MDX** (4.6%) - Blog content
- **JavaScript** (3.3%)
- **TypeScript** (2.9%)

## Getting Started

```sh
npm install
npm run dev
```

Visit `http://localhost:4321` to see the site locally.

## Building

```sh
npm run build
```

The production build will be output to `./dist/`
